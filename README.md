# Sikkanam – Tamil Nadu Budget Travel Planner

Sikkanam is a budget-first travel planning platform designed to help travellers explore Tamil Nadu affordably.

The platform generates realistic travel plans by combining transportation, accommodation, food estimates, local expenses, and destination recommendations into a single itinerary.

## Features

### 🚆 Railway Journey Assistant
- Railway station-aware travel planning
- Direct train route suggestions
- Train search integration via RailYatri
- Multi-leg journey recommendations

### 🏨 Smart Hotel Recommendations
- Hotel discovery using OpenStreetMap data
- Budget-friendly accommodation suggestions
- Direct links to check live hotel prices
- Hotel fallback system for better coverage

### 🗺️ Route Planning
- Optimized travel routes
- Train, bus, and mixed-mode transport planning
- Distance-aware travel recommendations
- Maps integration

### 💰 Budget Engine
- Transport cost estimation
- Hotel budget allocation
- Food expense estimates
- Local transportation budgeting
- Budget fit analysis

### 📄 Sharing & Export
- WhatsApp itinerary sharing
- Print-friendly trip summaries
- PDF export support
